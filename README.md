# 星陨边境 · Starfall Frontier

在原有 Unity 2D RPG 项目上实现的一款动作 RPG。以原 Viola 金发角色为共同主角，包含九个地区与炉火旅店、两条相互影响的剧情线、三职业、同伴、成长、制作与生活系统。

一颗星坠落后，森林狂暴、遗迹被淹、矿场不停运转。你接受公会委托寻找星核，却逐渐发现堡垒的屏障正在抽走边境的生命。

《远岸来信》扩展让你追查港口、沙海与高原的原始记录。守灯、救人、供水与公开真相都需要付出代价；你不仅要决定相信谁，还要建设足以兑现承诺的设施。

本轮继续检查延迟伤害与恢复状态，修复 Q 前摇/连锁击杀后属性变化、冰霜借用后来装备与位置、某些帧间隔多一次冰霜伤害、同伴替玩家完成教学，以及深渊操作打断死亡恢复。62组生产核心回归通过，含三职业18,000帧组合操作。复现与修复见 [DELAYED-SKILL-RECOVERY-BUGFIX.md](docs/DELAYED-SKILL-RECOVERY-BUGFIX.md)，最终验证见 [QA-REPORT.json](docs/QA-REPORT.json)。此前状态边界修复和全项目逐项复查继续保留。

历史登记的 256 图格、22 张角色原始注册和 44 张预生成遮罩资料仍保留，供审计参考；**旧独立头部、腰部拼接算法已退出当前主角正式运行时**。真实迁移状态及未完成原画见 [动画根因与现状](docs/HERO-ANIMATION-ROOT-CAUSE-2026-10.md)，早期尺寸／握持修复记录见 [FRAME-CONTINUITY-POLISH.md](docs/FRAME-CONTINUITY-POLISH.md)。

## 启动

1. **获取正确分支**：备份旧工程，克隆／拉取本仓库 **`chatgpt/dev`**，从其包含 `Assets`、`Packages`、`ProjectSettings` 的工程根目录打开，保留原 `.meta` GUID 与 Git LFS 素材。不要把过期 ZIP 或 `main` 全量覆盖较新的 `chatgpt/dev`。
2. 用国际版 **Unity 2022.3.53f1** 打开项目。版本文件只保留一行 `m_EditorVersion: 2022.3.53f1`。新建项目时选择 **2D / Built-In** 后关闭，再覆盖上述文件。若已能运行的国际版 2022.3 LTS 是其他补丁号，这一行填写它的真实版本号。
3. 导入结束后双击 `Assets/Scenes/Frontier.unity`，点击 Play；也可用 **Starfall → Play Adventure**。
4. 新游戏带八步入门与镇内三阶段实战练习；旧存档可直接继续，F1 随时查看十二类冒险指南。

默认构建场景已经切换为 `Frontier.unity`。原 `SampleScene.unity` 和原动画仍保留，供继续开发与比较。

## 可以玩到什么

- **先锋**：短剑起手、更多生命，护盾斩提供范围攻击和三秒减伤。
- **游侠**：猎弓起手、移动更快，扇形箭雨发出五支强力箭。
- **星术师**：法杖起手、耐力回复更快，星火新星造成大范围伤害；法杖普通攻击可爆炸溅射。
- 三条五级天赋分支：攻击与暴击、生命与减伤、移动与闪避。
- 城镇与四章主线：密林救援、遗迹石碑、矿场修复、堡垒终战。四位 Boss 各有三个生命阶段。
- 敌人包括追击怪、远程攻击者与重型敌人；支持绕过地形的寻路、攻击预告、弹幕、援军、伤害数字和战斗奖励。
- 武器制作、五级装备强化、资源采集、种植、钓鱼、料理增益和三项镇民委托。
- 三种结局。完成全部镇民委托后开放共同重建边境的路线；结局后可继续游玩，也可回到堡垒重看其他已满足条件的结局。
- 中英文、三档难度、音乐/音效/环境声独立音量与总开关、减少动态效果、自动/手动存档、校验和备份恢复、失去焦点自动暂停。

## 远岸来信：新增深度与广度

交回第一枚星核后，找余烬镇的露恩 `(26,9)` 接取调查。原主线和远岸剧情可以交替进行；Tab 手帐可选择追踪目标。新的协定有三种结果，与原主线的三个结局分别保存。

| 地区 | 主要玩法 | 剧情影响 |
| --- | --- | --- |
| 雾港 | 每36秒变化的潮汐、控潮闸门、乘客救援、信号塔修复 | 决定救援与守灯优先级，改变两方声望 |
| 玻璃沙海 | 实际显示光路的转向镜、绿洲降温、沙舟风旗竞速 | 决定蓄光机供给绿洲还是航路 |
| 霜钟高原 | 可调四种音高的钟阵、寒意、火盆、原始记录 | 决定私下纠正还是公开受害者名字 |
| 地脉深渊 | 六层种子地图、祝福搭配、三档风险、逐层结算 | 永久遗物、成长奖励与可重复远征 |

- **三名同行者**：米拉治疗与护盾，伊沃远程与贯穿箭，森冻结与持续领域。一次带一人，自动支援和 Z 指令均有实际战斗效果。个人故事与每日分享炖汤提升羁绊。
- **六件遗物、两个槽**：治疗闪避、满血增伤、移动与耐力取舍、反击窗口、技能治疗与耗能取舍、暴击与承伤取舍。城镇记忆工坊用碎片锻印，最多三级。
- **战斗成长**：短剑连击、破势后的反击、完美闪避返还耐力、三类武器熟练度，以及每职业一种可切换的第二 Q 技能。第五级可消耗一个技能点学习。
- **三项两级建设**：水渠提高药草收成；驿站开启野外休整与每日凉茶；工坊开启遗物锻印并降低费用。建设同时争取山野议会支持。
- **六类轮换悬赏**：清路、矿石、钓鱼、守护者、重甲与深渊勘测。接取后计算进度，报酬只能领取一次。
- **三方协定**：供水增加收成；灯网降低快速旅行所需的安全距离；共同治理缩短同伴指令冷却并增加碎片收益。三份证词与共同治理还会解锁说服原主线统领的和平路线。
- **十七篇可重读记录**：未寄出的信、六处旧日补给与旅店赊账簿讲述巡路队的往事。剧情线之间通过人物、技术、船票和供能记录互相解释；世界记录支持分页。
- **深渊断点保存**：楼层、种子、祝福、待结算收益及存活敌人的生命和位置可恢复。倒下或提前退出只丢当前楼层未结算收益，之前结算的奖励保留。

详细任务、机关、竞速和协定条件见 [docs/WALKTHROUGH.md](docs/WALKTHROUGH.md)。剧情设计与版本变化见 [docs/EXPANSION.md](docs/EXPANSION.md)。

## 验证与当前限制

`python3 tools/run_core_tests.py` 会编译实际 C# 游戏核心并执行当前回归检查；测试组数量会随开发变化，以实际输出和最新 Actions 为准。Unity EditMode 有对应包装与额外原生 JSON 检查，但不在普通 Mono CI 中执行。需要 Python 3 和 Mono (`mono-mcs`)。包含原主线三职业标准难度通关、港口三个方案与三个协定、三职业六层深渊、和平解决原主线、地图可达性、潮汐安全、气候与凉茶、竞速、遗物取舍、专精、每日赠礼、交易、生活、旧存档迁移与深渊断点恢复。还包含实战教学、能力支路、武器打法、遭遇快照、菜单焦点、声音规则、接触时序、飞行物、死亡途中恢复、室内碰撞、同伴动作同步、物理攻击/闪避阻挡，以及本轮出生脚底、涨潮前置、状态停止和历史缓存回归。

也可在 Unity Test Runner 的 EditMode 中运行 `Starfall.Tests`。

`Starfall → Visual QA → Open Review Lab` 提供独立的职业/地区/Boss测试场，可冻结、逐帧推进、实战与原生截图；测试场不写入旅程存档。Test Runner 的 PlayMode 中另有 `Starfall.VisualTests`。本环境未执行这些原生测试。`python3 tools/check_editor_syntax.py` 只对 Editor 菜单／导入代码使用离线声明进行编译；`python3 tools/check_native_hero_capture_compile.py` 对真实 Unity 条件编译的主角 SpriteRenderer C# 进行独立离线编译及无效 API 故障注入。两者**均不是原生 Unity Editor PlayMode 验收**。

开发环境没有 Unity 编辑器或 Player。核心检查已经执行；运行时 C# 的离线语法与布局检查已执行。**这不是 Unity 编辑器编译、真实窗口试玩、音频试听或平台构建验证**。请打开上述场景完成这一步。

`python3 tools/run_layout_checks.py` 可重建生产 `OnGUI` 调用的离线布局预览，并执行真实临时目录中的存档文件恢复及菜单输入检查，需要 Mono、Python、Pillow 与 FontTools。`docs/previews` 展示新地图和中英文界面；字体指标、动画、音频和 Unity 的最终结果可能存在差异。数量与结果见 [docs/QA-REPORT.json](docs/QA-REPORT.json)。

## 项目结构

| 位置 | 用途 |
| --- | --- |
| `Assets/Scripts/Frontier/Core` | 独立于引擎的战斗、任务、成长、生活和存档数据规则 |
| `Assets/Scripts/Frontier/Runtime` | Unity 输入、像素场景、界面、音频、存档文件 |
| `Assets/Resources/Frontier/Campaign.json` | 地图、居民、交互物、Boss 与剧情数据 |
| `Assets/Editor/Frontier` | 场景启动、字体和图片导入、平台构建 |
| `Assets/Tests/Frontier` | Unity 与命令行共享的回归检查 |
| `Assets/Tests/PlayMode` | Unity 原生图集、方向动作、Boss时间线与截图检查 |
| `Assets/ArtSource/Frontier` | 本轮原始绘制图，不进入 Resources |
| `tools` / `tests` | 命令行测试与离线布局检查；不进入游戏构建 |

自动存档仍位于 `Application.persistentDataPath/starfall-v1.json`，手动位置位于 `starfall-slot-1.json` 至 `starfall-slot-3.json`。数据版本2，外层增加校验封套；原版本1/2的裸JSON可以读取并迁移。写入保留 `.bak`，读取可恢复有效备份或中断临时文件。独立调用存档规则时，先执行 `GameCore.PrepareSave()` 再序列化 `save`，以保存当前地区/深渊存活敌人和石碑进度。原角色脚本的移动、死亡、资源扣除等修复继续保留。
