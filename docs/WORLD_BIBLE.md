# 星陨边境 / STARFALL FRONTIER
## 叙事圣经 v1.0 — 《把路还给人》

> 单一主题：所谓拯救，不是把所有人关进永不熄灭的墙，而是让每一个人有能力安全归家，并共同决定自己承担的代价。
>
> Core theme: Safety is not a wall that never falls. It is a road home, and the right to decide who pays for it.

### 0. 使用范围与设计契约
本文是当前正式版本的世界观基准。不是推翻已实现玩法的平行设定，而是为已经存在的主线、远岸、星图、巡路队、星核、各地区机制与三个结局建立统一因果关系。

**不可改写的游戏事实**：唯一金发主角可以使用战士、游侠、法师装备形态；前四章为余烬镇→荆棘密林→沉没遗迹→赤铁矿场→星陨堡垒；远岸在第一枚星核交回后可以平行开始；远岸的雾港、玻璃沙海、霜钟高原顺序解锁；已实现的三个原版结局、三种远岸协定都存在，属于两个相互呼应但独立结算的抉择。游戏中现有技能、道具数量、战斗节奏、地图通行条件和存档 flag 均优先于新增叙事。正文对白中“星核归还”仍指主角取得星核后把保管权交给公会，最终选择才决定星核的长期供能去向。

## 第一部：真实的世界

### 1.1 星根、七锚与星核
数百年前，边境的先民发现地底并非死矿。发出蓝白微光的**星根（Starroot）**是一张与水脉、植物、热流和古城机械互相耦合的天然脉络。它能让河道在旱季回流，让高原火盆保存余热，也能借石碑与铜镜传递光与讯号。古文明在星根的交汇处建造了**七座调谐锚点（Seven Anchors）**，使能量流动不至于在任一地区暴涨或枯竭。

调谐锚点的结晶核心，民间称**星核（Starcores）**。星核不是无限能源，不是能安全复制的炸弹，也不是怪兽掉落的普通魔石。它们像河上的闸：改变一个地方的供给，就会影响其他地方。**星晶（Starcrystals）**是脉络中过剩或泄漏能量凝成的矿物，可做工具、灯与法杖的耗材；过度开采会伤害周围的星根。

**星陨（the Starfall）**不是说天上有一颗整齐的矿石砸到世界，而是整个星根网络在过载时从天幕到地下同时爆出碎光、断层与“流星雨”。星陨当天，星核调谐紊乱，原本处于守护状态的古代机关失控，受根系影响的野兽成为危险的护巢者。它们并非无理由邪恶。

### 1.2 九年前、七日前和今天
- **九年前**：赤铁矿与玻璃沙海的旧供给体系已经衰败；玻璃城的主人死去，蓄光机仍忠实遵循“为主人每天留一杯水”的命令。问题是旧制度拒绝更新，不是机器突然产生恶意。
- **数年来**：星陨堡垒由星卫统领**厄洛（Orrin）**主持修复防护屏障。他确实在早年灾害中救过人，却逐渐让外围地区为城内持续供能。公会内部产生分歧：统领需要运输星核，莉雅和巡路员更关心城外的生命。
- **七天前**：堡垒一次高强度供能与本已脆弱的七锚网络共振，引发大规模星陨。森林封路、遗迹涨潮、矿场失控；北部巡路队和部分测绘人员失踪。厄洛将灾难视为屏障仍不够强的证据，并要求继续回收星核。
- **故事开始**：玩家携带巡路员留下、准备送给莉雅的旧信来到余烬镇。你不是天命选定的“唯一救世主”，而是愿意真正走上那些被删除的道路、把人带回来的一个旅人。

这条时间线允许“星陨后的第七天”和“九年前的机器命令”同时成立。

### 1.3 权力体系与三方阵营
**星卫与堡垒（Starwardens/Citadel）**：军事防护和核心调谐权集中在城墙内。厄洛相信只要屏障不灭，人们总有机会；他的错误不是假装在保护人，而是把谁有资格活在墙内当作既定答案。

**守灯会（Lamplighters，reputation[0]）**：维护灯塔、信号塔、山路钟阵和远距离通讯。主张航线与基础照明不能在灾害来临时停摆；但曾配合错误报表，对停灯代价以外的代价视而不见。

**摆渡盟（Ferry Union，reputation[1]）**：渔民、摆渡人、沿河聚落与避难船。主张优先救眼前能救的人；但熄灭所有远海灯塔也可能让更远处的船遇难。

**山野议会（Wild Assembly，reputation[2]）**：林地药师、村民、绿洲和生态守护者。主张水与土地不能只是屏障的燃料；但恢复生态也需要航路和工程技术。

**巡路队（Roadwardens）**：曾是跨越阵营的护送与测绘队伍。它们秘密将未被许可的疏散路线分段写入信标、旧信和地图，保证官方道路被封时，旅人仍知道怎么回家。巡路队并非凭空出现的另一支军团，而是公会内部坚持原初职责的一批普通人。

### 1.4 技术、魔法与经济
主角始终是同一个金发旅人。战士、游侠、法师表现为装备和战斗技艺变化，不是三位平行主角。短剑靠材质和破势、猎弓靠发射机构、星火杖靠引导星晶脉冲；法术属于可训练的星根调谐技巧，不与世界规则冲突。闪避、完美反击、破甲、弹幕与攻击前摇都是可学习的生存能力。

药草、木材、鱼、零件和星晶不只是商店货币：药师分配药品、渔夫保障食物、铁匠为水泵与灯塔制造同样规格的零件。这解释了为什么从背包拿出两份材料能改变救援路线，也解释了为什么“修好一口井”有时比多建一面墙更有价值。星核让封印重新调谐，玩家因而获得藤封共鸣、浅水接通和断桥修复的能力，得以返回旧地区探索。

## 第二部：主线《光墙与归途》 / THE WALL AND THE WAY HOME

### 序章 · 余烬镇 / Emberfall
**目标**：救回失踪的侦察员，而不是先去争夺力量。莉雅负责公会民生事务，她收到了巡路队未能送完的旧信。她相信交回星核是当下稳定地区的唯一办法，却保留“有人正在为此付出代价”的怀疑。阿茴的旅店是实际的避难网络：热汤、休息、补给、赊账簿、星图桌都服务于这个身份。

**情绪线**：从具体的人开始，而非从天选预言开始。

### 第一章 · 荆棘密林 / Thornwood：森林为何封路
森林的星根被采矿令割断，苔根脉络开始以荆棘自保。**黑荆巨兽（Briar Beast）**是被错误供能惊醒的守巢者，不是纯粹侵略者。救侦察员、击退失控兽群、安抚祭坛，玩家发现堡垒正从森林星核抽能。取得第一枚星核，是为了停止地方暴走并把可追溯证据带回镇上；它最终属于谁尚未决定。

**核心关卡行动**：先清理四名拦路敌人救侦察员；打开放置星核的祭坛；获得藤封共鸣，使旧藤封支路可以重访。

### 第二章 · 沉没遗迹 / Drowned Ruins：机关记得次序，人要记得理由
这里的先民用“日→月→潮”控制水脉闸门。后来系统被改成只认中央命令，失去授权的人被留在桥外。**溺水守卫（Drowned Sentinel）**仍机械地保卫闸门，其攻击是水脉过载的表现。玩家解开石碑，理解把控制权从一个命令还给实际需要渡河的人。

**行动**：调查遗物找到正确碑序、打开道路、击败守卫、取得第二枚星核与浅水接通能力。

### 第三章 · 赤铁矿场 / Ironreach：机器为谁运转
赤铁监工和自动设备奉命日夜运转，把供能矿石运给堡垒，而矿工却没有足够零件修桥、抽水、照明。**铸铁监工（Iron Overseer）**体现不愿修正的旧指令，并非拥有道德恶意的机器人。玩家收集零件修复升降机、击败监工、取得第三枚星核与断桥修复能力，同时理解建设并不等于征用。

### 第四章 · 星陨堡垒 / Starfall Citadel：安全属于谁
**厄洛**亲眼见过失去屏障的灾难，也知抽能在毁坏外围，却害怕关停后再也保不住任何人。他不是为了制造悲剧而制造悲剧。他必须在战斗或证据面前承认：只为一座城加高墙，不是修复星根网络的办法。

玩家与厄洛相对时拥有三种保持原有机制的选择：
1. **《重新生长》**：把核心重新接回地方锚点，堡垒屏障消退，土地逐步复苏；风险由居民共同承担，厄洛在城外学习建设。
2. **《高墙之内》**：保留屏障，开门容纳更多居民，短期防御较稳固；土地衰弱仍在继续，这是能理解却有沉重代价的选择。
3. **《我们的边境》**：需得到杏、老潮、诺尔三人的支持；不将能量垄断于城墙，而以药品、食物、水泵和跨地区支援建立分布式的互助道路。改变不是瞬间消除全部风险，而是让不属于城墙的人也有决策权。

如果在远岸取得三份原始证词，并让协定先在现实中运作，厄洛可被说服放下武器。这是对“用实际替代方案回答恐惧”的奖赏，并非突然解除人物动机。

## 第三部：远岸《每一份代价的名字》 / LETTERS FROM AFAR

远岸任务可在回收并交还第一枚星核后，与主线**平行**展开；它并非默认发生在主线结局之后。

### 雾港 · Mistport：灯与船
屏障抽能影响涨潮和旧灯塔，潮壳海兽吞食含星晶废水，受刺激后吐出毒潮。米拉失去弟弟；他没有消失在纯粹的数字里，而是留下一份载有撤离路线的乘客名册。守灯会要求修塔以指引远海船只，摆渡盟要求先救眼前溺水的人。玩家可以守灯优先、救人优先或协调路线；三种优先级都可以推进剧情，因为双方有真实的理由。

**核心行动**：潮汐时序、控潮闸门、信号塔维修/乘客救援、潮壳海兽、提交水位记录。

### 玻璃沙海 · Glass Desert：九年前还在生效的命令
光镜、蓄光池和自动守卫沿用九年前旧城主人的配给政策，即使受益者早已不在。酷热不断积累；绿洲树荫和凉茶给玩家真实的庇护。伊沃不是在“击败邪恶 AI”，而是要让一台守卫承认命令可以改变。玩家决定将修复后的系统优先给绿洲供水，或给远岸灯网供能。

**核心行动**：三面镜子的东/南/东光路、降温、沙舟竞速、玻璃守卫、调度日志。

### 霜钟高原 · Frostchime：钟声掩盖了什么
旧钟阵保护山路，但低频也掩盖了冰下的求救声。森每天为没能回来的人敲钟；霜钟执事相信公布真相会瓦解居民最后的信任。玩家依第三/第一/第二音校准三面钟，点燃火盆抵御寒冷，击败执事，并选择私下保存证据、推动纠正，或公开每个人的名字。

**核心行动**：钟阵音高、寒意与火盆、霜钟执事、被封存的名单与纪念碑。

### 三方议事厅：协定不等于结局
水位、调度单、死者姓名必须同桌核对。到此玩家达成三种**远岸协定**：共同水渠（农业优先）、轮值灯网（交通优先）、开放星路（共同治理，需要工程建设、同伴支持和三方声望）。此处结算的是远岸治理方案，与主线三种核心结局分别保存、并行生效。主线结局讨论星核分配；远岸协定讨论谁负责管理设施、核实代价、回应居民。

## 第四部：所有已开发支线如何归入世界

**三地失联旅人 / Missing Travelers**：茉伊、艾鲁、塔尔不是抽象领取奖励的 NPC。护送他们代表跨区域互助；捐赠材料提高相关阵营信任，亲自守护提高武器熟练度。防守对象的安全度解释了为何敌人会攻击旅人而不是只追击主角。

**归乡星图 / Homeward Chart**：三枚巡路信标其实是旧救援网络的分段路标。拼成地图获得永久速度与安全往返，是对跨地区路线知识的具体奖励。

**三封未寄出的信 / Roadwarden Ciphers**：杏送药、老潮渡船、诺尔修机器，分别回答“救谁、怎样救、谁决定工具的用途”。正确解谜不只拿奖励，还让玩家学会本作中心道德命题。

**守路试炼 / Beacon Vigil**：敌人会侵蚀信标，因为城墙以外的道路也需要维护与看守；波次修复和精英复战体现巡路人反复执勤，不能重复领取首胜酬劳。

**失落测绘师的星图 / Lost Surveyor Atlas**：测绘师的三段记录是避开断根、失控水闸和矿区坍塌的撤离图，而非藏宝图。琳修复后成为居民共同使用的资料。矿场的**测绘师回声（Surveyor's Echo）**是旧方位校准装置启动的防御投影/残存指令，不是被复活的巡路员灵魂；它旋转的三向打击正是罗盘式校准协议的危险重现。

**远岸气象站 / Farshore Stormwatch**：三座修复站分别能暂时稳住低潮、缓解沙海热度、缓解高原寒意；它们是小规模、当地负责维护的可持续方案，与单一大屏障形成实际玩法对照。三站联通后可安全旅行；完成巡测后能共享天气预测，解释为何必须实地往返读取数据。

**城镇工程、悬赏、同伴与个人剧情**：玩家不会一拳解决社会问题。工程等级代表地方修复能力，声望代表同意承担责任的人，悬赏帮助维持日常治安，同伴（米拉、伊沃、森）需要先解决各自地区危机才愿意同行。个人委托表现他们从单一职责中取得自己的声音。

**地脉深渊 / Root Abyss**：六层地底不是“击败所有邪恶根系”的反转。它是七锚的剩余调谐管道，曾被当成灾时备用储能与试验场；每层风险、祝福与未结算资源都表现过度提取的诱惑。只有远岸已经建立治理方案，居民才允许深入修复而非再度封锁根系。

**战斗美术与主角统一**：所有职业共享一个金发主角身份。战斗动画的 Idle/Walk/Attack/Cast/Hit/Death/Dodge/Block 等不是各职业身份的矛盾；它们是同一个人的身体行为。RPG 的打击反馈、双阶段 Boss 预警、投射物真实飞行、碰撞与 UI 可读性依旧是制作品质要求，不因剧情改写而回退。

## 第五部：角色小传与情绪弧

- **主角 / The Traveler**：同一位金发旅人，带来未投递的信，从执行委托走向提出问题。玩家决定选择力量的去处，但不被绑定到“高贵血脉”的强制设定。
- **莉雅 / Lyra**：公会民生接待员。相信将星核交回可以止乱，却逐渐见证枯萎、援助和证词。其转变不是瞬间反抗，而是学会不再替其他人作决定。
- **厄洛 / Orrin**：城墙守护者，因真实的丧失形成过度保护。他必须面对自己防线的隐藏账单；可被决斗击败，也可被可信的合作证据说服。
- **杏 / An**：药品不只沿授权道路发放，拒绝让村庄成为“无药可救”统计数字。
- **老潮 / Old Tide**：允许无钱乘客用故事作船费，讲述与尊严同样是补给。
- **诺尔 / Noll**：机器不自动代表公正，用图纸的人要为机器服务的对象负责。
- **露恩 / Lune**：远岸的递信者，将地方遭遇汇成可被审查的原始记录。
- **米拉 / Mira**：在“救起了一船人”与“弟弟没有回来”的两种事实间重建领导力。
- **伊沃 / Ivo**：维修工程师，懂得机器要有可被改写的责任人，而不应服侍逝去主人。
- **森 / Sen**：敲钟者，宁愿一个一个念出姓名，也不让集体损失成为不必回答的数字。
- **琳 / Lin**：修复师，证明地图不是资源支配图，而是公开的求生知识。

## 第六部：分镜、叙事节奏与制作约束

序章提出**“谁没有回来？”**；密林提出**“谁把土地当燃料？”**；遗迹提出**“规则记得什么？”**；矿场提出**“工具替谁工作？”**；堡垒提出**“安全谁来决定？”**。远岸用**“代价有名字”**来检验玩家的答案。结局不直接宣称某一方案使所有问题立刻消失。

对白优先顺序：先让玩家知道眼前的具体问题 → 再交代此地的过去 → 再提出带后果的选择 → 最后给出下一个可操作目标。保留全部现有 action id 和 flag；不新增强制过场阻断玩家行动，不允许自动获得已存在的战斗/任务奖励。重要真相采用渐进披露：未完成前不要在世界档案泄露厄洛的内部账目、弟弟的下落、高原名单或三方协定结论。
